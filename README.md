# AR Methods Leads

Lead finder for AR Methods: type a suburb and a business type, and it pulls
businesses from Google Maps and shows which have no website. Save leads to a
call list, track each call, and download as CSV.

Live page: https://amanraju024-cmd.github.io/web-hustle-leads/

- Runs entirely in the browser. Each user pastes their own Google Maps API key
  (Places API (New)); it's stored only in that browser and sent only to Google.
- The call list is stored in the browser too, so download it as CSV to keep a copy.
