Lead Finder: find local businesses with no website, then call them

One-time setup: paste your Google Maps API key. It's saved only in this browser on this device and is sent only to Google.

  1. Open Google Cloud Console, create a project and turn on billing (there's a free monthly allowance).
  2. Search for Places API (New) and click Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key and copy it.
  4. Recommended: edit the key, set Website restrictions to this page's address, and restrict it to Places API (New).
